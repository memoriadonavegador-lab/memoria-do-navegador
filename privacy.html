Memória do Navegador — Política de Privacidade

Última atualização: 6 de outubro de 2026

Resumo

A extensão Memória do Navegador foi criada para permitir que o usuário guarde cópias locais de páginas que visita e consulte essas cópias posteriormente, inclusive quando o site original estiver indisponível ou o computador estiver offline.

Quais dados são tratados

Quando o salvamento automático ou manual é utilizado, a extensão pode armazenar localmente informações relacionadas à página, incluindo título, URL, data e hora, texto e estrutura HTML da página e, quando possível, imagens usadas pela página.

Vídeos não são baixados pela extensão.

Onde os dados ficam

As cópias são armazenadas localmente no armazenamento da extensão no navegador.

Quando o usuário configura a sincronização, as cópias são gravadas na pasta escolhida pelo próprio usuário para o Google Drive. A sincronização dessa pasta é realizada pelo Google Drive para computador, de acordo com as configurações da conta e do aplicativo do usuário.

O desenvolvedor recebe esses dados?

Não. A extensão não envia o conteúdo das páginas salvas para servidores controlados pelo desenvolvedor e não usa esse conteúdo para publicidade, análise comportamental ou venda de dados.

Serviços de terceiros

Quando o usuário opta por utilizar o Google Drive, os arquivos são sincronizados pela infraestrutura do Google Drive e ficam sujeitos aos termos e à política de privacidade do Google. A extensão não solicita acesso irrestrito ao conteúdo do Google Drive; ela utiliza uma pasta escolhida pelo usuário e a sincronização local do Google Drive para computador.

Uso de dados e Chrome Web Store

Os dados são utilizados exclusivamente para fornecer as funções descritas acima: salvar, pesquisar, visualizar e sincronizar as páginas selecionadas pelo usuário.

A extensão não vende dados, não usa dados para crédito ou empréstimos, não usa dados para publicidade personalizada baseada no conteúdo das páginas e não transfere dados para corretores de dados.

Segurança

A extensão foi projetada para manter os dados no dispositivo e na pasta do Google Drive escolhida pelo usuário. Cópias salvas são tratadas como conteúdo do usuário. Ao visualizar uma cópia, conteúdo executável como JavaScript da página salva é desativado para reduzir riscos.

Exclusão

O usuário pode apagar páginas individualmente ou apagar todas as páginas da memória local pela própria extensão. Arquivos já sincronizados com o Google Drive são arquivos do usuário e podem precisar ser excluídos da pasta do Drive separadamente, conforme a configuração usada.

Contato

Para dúvidas ou solicitações relacionadas à privacidade, utilize o endereço de contato informado na página da extensão na Chrome Web Store.
